# SourceDayZ Releases

Repositório de releases do jogo SourceDayZ.

O launcher consulta:

https://github.com/Arthurnashh/DayZSOURCE/releases/latest/download/manifest.json

Cada release contém o manifesto e os arquivos do jogo (um asset por arquivo).
O launcher baixa apenas o que mudou e confere o SHA-256 antes de instalar.
